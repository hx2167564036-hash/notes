# 444 天


期末周果然是所有大学生的噩梦 nightmare

基本不去图书馆的我在期末周的压迫与自己有点慌张的情绪下已经连续去了好几天的图书馆了。但是又不得不说，在图书馆学能静许多，如果是在寝室的话可能坐半个多小时就坐不住了 hhh，这也是人之常情。

今天是本学期最后一天上课，明天就开始没课，然后就是期末考惹。还是很紧迫吧，虽然我自我感觉我已经算复习的比较早的了。目前是复习了计算机网络和操作系统的内容，当然也都还没有完全复习好 hh，数据库目前是完全还没有开始复习，今明几天也得看起来了。考试的安排是这样的，27 操作系统，28 习思想，3 数据库，4 计算机网络。所以我们基本可以把他分成两段来看，毕竟中间还隔着一点时间。但是肯定肯定是不能把那两门的内容全部留在那个时候复习的 hh，这就意味着最近也要推进一些进度，留下一些到那几天。感觉我的复习思路还算清晰 hh

晚上考完了 Python 的晚课的考试，那肯定是满分拿下吧 hh，毕竟他是一个可以用手机帮助的考试。虽然平时分数在一些不愉快的影响下可能会不太理想，但是现在我也只能接受了～
